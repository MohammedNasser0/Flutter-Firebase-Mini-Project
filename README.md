*** Flutter Firebase Mini App

*** Description :

A Flutter application integrated with Firebase Authentication
and Cloud Firestore.

*** Technologies :

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase CLI
- FlutterFire CLI

*** Features :-

** Authentication :
- User registration
- Email/password login
- Logout

** Firestore :
- Add user data
- Store data in Cloud Firestore
- Retrieve saved records
- Display saved records
